---
name: maintain-changelog-and-test-requirements
description: Use this skill to ensure that all changes are documented and tested appropriately.
---
1. Create a template for the CHANGELOG.md that includes sections for new features, fixes, and breaking changes.
2. Require that every code change includes an entry in the CHANGELOG.md under the appropriate section.
3. Establish a rule that every bug fix must be accompanied by a regression test.
4. Create a dedicated test file for each bug fix to ensure that it is covered by automated tests.
5. Review the test coverage regularly to ensure all critical paths are tested.
6. Use a consistent format for test function names to improve readability and maintainability.
7. Document the process for adding tests and updating the changelog in the project guidelines.
8. Encourage team members to write tests as they develop new features or fix bugs.
9. Conduct periodic reviews of the changelog and test coverage to ensure compliance with established standards.
