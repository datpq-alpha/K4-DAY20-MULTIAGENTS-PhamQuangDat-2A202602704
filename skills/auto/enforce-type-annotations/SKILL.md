---
name: enforce-type-annotations
description: Use this skill to ensure all public functions have complete type annotations.
---
1. Review all public functions in the codebase for missing type annotations.
2. Add type annotations for all parameters and return values in public functions.
3. Use static type checkers (e.g., mypy) to validate type annotations across the codebase.
4. Establish a code review process that includes checks for type annotations.
5. Document the expected types for function parameters and return values in docstrings.
6. Create a checklist for new code submissions to ensure type annotations are included.
7. Regularly audit the codebase to identify and rectify any missing type annotations.
8. Encourage team members to adopt type annotations as part of their coding standards.
9. Provide training or resources on the benefits of type annotations for the team.
